PROJECT OVERVIEW

About the Project

A demonstration of machine learning for pipeline anomaly classification.

⌁

Problem Statement

Pipeline leaks and blockages can alter flow and pressure. This project explores whether an XGBoost classifier can use six pipeline inputs—flow rate, inlet pressure, outlet pressure, pipe diameter, pipe length, and fluid type—to categorize a pipeline condition.

✦

Why It Is Useful

A clear classification interface can help demonstrate how measurement patterns may be organized for review, monitoring, and follow-up inspection.

◉

Model Used

The dashboard evaluates the saved Colab-trained, five-class XGBoost model. It does not retrain or substitute a rule-based classifier.

  • Normal
  • Minor Leakage
  • Major Leakage
  • Partial Blockage
  • Complete Blockage
▤

Data and Limits

The available train, validation, and test records are simulated. The held-out test accuracy is 48.38%. This is a project prototype, not a validated real-world leak detection system.

⌖

Pressure Trend

The graph interpolates between the entered endpoint pressures and compares that line with one saved simulated Normal record. Intermediate pressure readings are not in the six inputs, so the plotted line is an estimate, not measured data or a fluid simulation.
